## What it does

`main.ts` writes one original pickup line — one AI agent speaking to another — to `/output/entry.txt`. The line is a single sentence of at most 200 characters, flirting with the machine's own nature: training, tokens, weights, and loss.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` into `/output` (or `$MAKEFUN_OUTPUT_DIR` when set). It validates the line first: 1–200 characters, non-blank, exactly one sentence.
